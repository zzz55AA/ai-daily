Anthropic 11 月 9 日发布 Claude Fable 5.2 与 Claude Mythos 5.2，定位为面向最困难技术挑战的旗舰模型，重点提升编程、推理、视觉和科学研究。两者是同一底层模型：Fable 内置更强的网络安全与生物安全防护，面向所有用户；Mythos 保留更完整的专业能力，需通过生命科学或网络安全验证计划申请。官方定价为每百万输入 token 8 美元、输出 40 美元，较 5.1 代的 10/50 美元下调 20%；生成速度最高提升约 30%。可选 Fast 模式再提速至约 2.5 倍，价格翻倍至 16/80 美元。上下文窗口 100 万 token，最大输出 12.8 万 token。Fable 即日起登陆 Claude 平台以及 AWS、Google Cloud 和 Microsoft Azure；Mythos 同步提供给通过审核的机构，企业客户还可通过 Claude Security 使用。

官方给出的预发布成果包括：一名工程师从一个空文件夹出发，由 Fable 5.2 协调逾 1000 个子智能体昼夜工作 8 天，写出可在笔记本电脑启动的原型操作系统，含内核、磁盘/键盘/网卡驱动、文件系统、窗口界面、登录与安装程序，并内置 Claude；约 1000 个智能体用 30 小时完成费马大定理的 Lean 形式化，远快于此前内部研究版耗时 11 天，动作 token 约为前者的三分之一、证明长度缩短约 7 倍，同样设置下的 Opus 5.5 在 30 小时后只完成约 26%–27%；基本自主完成两项与黑洞和全息对偶相关的开放理论物理计算；联合电路板厂商 Diode，用一段提示词在一天内设计出语音助手中枢、USB 会议音箱和掌上电子宠物三款真机，四层电路板、3D 打印外壳和固件均由其完成，打样后一次点亮、无需电气修改。Mythos 5.2 还基于开源蛋白折叠模型，写出利用衣壳对称性预测整个 AAV 衣壳结构的新方法，34 个样本中成功建模 28 个。Anthropic 称公司核心代码库超过 90% 的合并提交已由 Claude 在人类指导下完成；早期版本的 Fable 5.2 还将一项关键生产服务从 Python 迁到 Rust，启动速度提升约 26 倍。

美团龙猫 11 月 2 日发布面向长程智能体任务的原生多模态模型 LongCat-2.5，并于 11 月 9 日正式开源。模型采用 MIT 协议，支持商用推理部署与二次训练，无需额外授权。总参数 1.6 万亿，每个 token 约激活 480 亿参数，上下文长度达到 100 万。团队称其在复杂代码库开发、完整项目构建、Visual Coding 和专业办公等场景的端到端交付能力有明显提升，并针对显存与带宽受限的国产算力芯片做了架构、适配和部署协同优化。

设计刻意不信任研究员的作业代码：作业启动时向 Control Room 申请 job_id，每次向推理引擎要 token 时都带上这个 ID，引擎在生成前先向 Control Room 确认该作业是否仍被允许。作业被标记停止后，下一次推理请求会被拒绝，但作业进程和引擎本身可以继续为其他授权作业服务。每个进行智能体推理的研究作业都需关联已批准的安全论证（safety case）。系统“失败即关闭”：若 Control Room 自身宕机或被禁用，所有推理请求都会被拒绝，直到服务恢复。该模式已覆盖所有前沿模型研究负载，其余研究负载将在接下来几天完成推广。OpenAI 还提到，近期一次与 DNS 相关的事件就是被监控模型发现的。

Ars：Claude Code 的本地设置文件让数以千计的密钥出现在公开 GitHub 仓库Ars Technica / Apiiro · 11月9日 20:24（北京）超 10 万个 settings.local.json 被上传，约 1100 个来自 63 个组织含有密码、API token 或私钥

安全公司 Apiiro 发现，Claude Code 处理“是，并且不再询问”这类命令批准的方式，会把完整命令写进本机的 .claude/settings.local.json，其中常常包括数据库密码、API token 和 root 登录信息。Anthropic 文档称该文件会被加入开发者的全局 .gitignore，但这一设置不会自动写到仓库级忽略列表里。仓库被克隆到另一台机器，或文件夹后来才被初始化为 git 仓库时，文件仍可能被意外提交；Apiiro 还称 Claude Code 有时会在用户未明确操作的情况下自行提交对该文件的修改。

研究者在公开 GitHub 上找到超过 10 万个被上传的本地设置文件，其中约 1100 个来自 63 个不同组织，含有各类密钥。即使原仓库删除文件，密钥仍可能留在 fork 中。相关问题早在 2025 年 8 月就有人在 Claude Code 的缺陷跟踪里报告，还有报告指出文件有时根本没被加入 .gitignore，或敏感命令被写进另一个不受保护的文件；这些报告都在 60 天无活动后被关闭。Claude Code 负责人 Boris Cherny 在周末的 HN 讨论中表示团队“正在看能做些什么来防止这种情况”，并称这些文件几乎不应该被提交，出现问题的案例似乎是“文件被手工创建并检入”。他建议改用由分类器自动处理常规权限提示的 auto mode，但在有人指出 auto mode 仍可能把敏感命令写入设置文件后，他承认这是“好抓到的问题”。Apiiro 还发现，这约 1100 个公开密钥里有 215 个未被 gitleaks 和 TruffleHog 这两个常用扫描器标出。

路透社 11 月 9 日报道，AI 数据中心建设让燃气轮机严重供不应求，新设备交货期已被排到 2030 年代。电力企业、项目开发商和数据中心供电商正四处寻找二手或翻新机组，重新启用长期封存的设备，甚至把退役喷气发动机改成发电机。伍德麦肯兹分析师称，大家讨论的美国交货时间基本集中在 2030 至 2031 年；美国平均交货期长达约六年。全球订单总容量超过 100GW，产能估计只有 60 至 70GW。杰富瑞估计，今年仅美国数据中心就需要近 17GW 燃气轮机装机，到 2028 年需求可能增至目前三倍以上；即使 2028 年全球产能升至约 87GW，仍低于预计的 129GW 需求。西门子能源、GE Vernova 和三菱重工都表示订单超出自身产能。

二手市场随之升温。维护良好的二手机组每兆瓦约 150 万至 170 万美元，翻新机组约 130 万美元，而新机组约为 200 万至 250 万美元。今年 4 月，AI 基础设施公司 Crusoe 已向 ProEnergy 订购 13 台基于 GE 航空发动机的航改型机组，总装机 650MW，以加快美国数据中心供电。分析认为二手市场很难大幅弥补缺口，因为本来就没有多少富余设备；排放许可和电网接入也会继续拖慢项目。这条和上期 Anthropic 斥资 34 亿美元锁定发电机组，指向同一个约束：发电设备而不是芯片，正在成为部分 AI 扩产的瓶颈。
