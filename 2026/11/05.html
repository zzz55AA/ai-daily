OpenAI 在 ChatGPT、Codex 和 API 中推出 Images 2.6，所有订阅档位在桌面、移动端和网页上都可使用。它能生成 GIF 动图，比如让品牌吉祥物动起来，或把产品图做成循环动画；多轮编辑时角色、产品和品牌细节也更一致。

生成速度比之前快 50%。API 提供两款模型：GPT-Image-2.6 Flare 在低质量档最快约 6 秒出图，并改进了海报和产品图的版式；GPT-Image-2.6 Sunburst 在中、高质量档画质更高，多轮编辑之间的一致性也更好。

API 还新增了 ChatGPT 中已有的图片标注（image markup），可以精确指定要修改的位置；支持导出 SVG；并新增 complexity 参数，用来控制模型为一个请求做多少规划。OpenAI 建议多数编辑任务用低 complexity。

OpenAI 称，ChatGPT、Codex 和 API 每周合计生成 40 亿张图片。OpenArt、Figma Weave 是早期接入的客户，系统卡另行发布。

NVIDIA 论文：频繁压缩上下文，前沿模型在长任务上几乎不掉分arXiv 2611.05306X · @omarsar0 · 11月4日 20:25Opus 4.5 每步只保留摘要，SWE-bench Verified 70.2 对比完整历史 70.0

据 Elvis Saravia 的介绍，NVIDIA 这篇论文研究了智能体任务中激进的上下文压缩：每一步只带一份简短的状态摘要，而不是完整对话记录。结果显示，Claude Opus 4.5 在 SWE-bench Verified 上得 70.2，对比保留完整历史的 70.0，中位峰值上下文从 32K 降到 8K token；在对话结尾做简单压缩，分数甚至从 70.0 升到 74.8。

这一规律在 Terminal-Bench、FRAMES、BFCLv3 和多语言 SWE-bench 上也大体成立，部分设置略有损失。论文还指出，前沿开源权重模型上越靠后的 token 生成成本越高，最多可达 7 倍。

微软 ParetoSaddler：同时按质量和成本优化智能体框架，成本偏好留到最后再用X · @omarsar0 · 11月4日 05:58（论文解读）GAIA2 质量从 56.22% 升到 62.89%，单任务成本从 0.78 美元降到 0.45 美元

DAIR.AI 的 Elvis Saravia 介绍微软的 ParetoSaddler 方法：优化器每一步修改一个父版本的智能体框架（harness），新旧版本各跑多次，再用贝叶斯自助法判断候选是否在质量或成本上有可信的进步。

它的核心思路是成本偏好只在搜索结束时使用。如果每一步都按成本筛选，会丢掉那些能演化出更好版本的中间候选。

在 GAIA2 上，质量从 56.22% 升到 62.89%，单任务成本从 0.78 美元降到 0.45 美元；在 ClawMark 上，质量从 70.86% 升到 81.35%，成本从 1.17 美元降到 1.01 美元。按帕累托挑出的框架在质量和成本上都好于只看准确率的优化。
