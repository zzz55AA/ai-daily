```bash
python3 scripts/import-reports.py --manifest 清单.json
```

清单里的 `file` 是该期选定的终稿，不按文件修改时间取舍。同一天可以有多份报告，跨日期的专刊也单独保留。Markdown 和 PDF 先原样留下并标明尚未转换。公开作者邮箱可以保留；疑似收件人、本机路径或密钥只报告类别和数量，不打印内容，对应的已批准稿也不会被悄悄丢掉。11 月 8 日必须是 83 条的终稿，11 月 10 日必须是补入 Anthropic 的 61 条终稿。

## 历史归档入口

- 首页 `index.html` 是总入口。桌面左侧是年、月、日和期号目录；窄屏收进顶部的「历史日报」抽屉。
- 目录里的搜索框可按日期、期号、标题或要点过滤，「跳到日期」可以直接选一个已发布的日期打开。
- 目录和搜索共用 `archive/index.json` 这份索引，不加载整期图片。
- `archive/index.json` 每条记录含 `date`、`issue`、`title`、`count` 和 `path` 等字段，`path` 就是该期正式地址 `年/月/日.html`。
- 按日期直连可用 `年-月-日.html` 跳转页，例如 `2026-11-19.html` 会转到 `2026/11/19.html`。
